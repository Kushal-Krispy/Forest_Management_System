# User Guide - Smart Forest Monitoring Platform

## Dashboard

The analytics dashboard shows forest health, fire risk, incident overview, and recent activity.

## Forest GIS Map

Interactive map with forest, wildlife, and incident markers. Use search and filters to explore.

## Incident Heatmap

Visual heatmap of incidents with severity color coding. Filter by date, type, forest, and severity.

## Wildlife Analytics

Population trends, birth/death rates, forecasts, and growth percentages with Chart.js visualizations.

## QR Wildlife Tracking

Each animal has a unique QR code. Scan or enter code to update health, location, sightings, or relocations.

## Officer Workflow

Manage incidents through statuses: Pending → Under Review → Verified → Resolved → Closed.

## Reports

Generate Forest Status and Incident Investigation reports with AI executive summaries. Export PDF, CSV, Excel.

## Notifications

Bell icon shows real-time alerts for incidents, fire risk, and wildlife events. Updates every 30 seconds.

## Environmental Monitoring

View temperature, humidity, rainfall, AQI, and water quality trends per forest.

## Export

Most data tables support CSV, Excel, and PDF export from list pages and the API.
