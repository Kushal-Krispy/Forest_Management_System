# Project Name

## Setup Instructions
1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository into your `xampp/htdocs` folder.
3. Open XAMPP Control Panel and start **Apache** and **MySQL**.
4. Go to `http://localhost/phpmyadmin` and create a new database named `your_database_name`.
5. Import the `.sql` file found in the `database/` folder of this project.
6. Access the project at `http://localhost/your_project_folder`.
